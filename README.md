SQL Concepts Demonstrated

Operation	Description

ORDER BY	Sort records in ascending or descending order
GROUP BY	Group records and perform aggregate functions
WHERE	Filter records based on conditions
INNER JOIN	Return matching records from both tables
LEFT JOIN	Return all records from left table
RIGHT JOIN	Return all records from right table
CROSS JOIN	Return Cartesian product of two tables
